# 《哈奇猫》题材改造方案

## 1. 目标与边界

把当前的“吸尘器/猫巷”题材整体改为《Chiikawa》原作同人方向的“小动物接讨伐委托、工作赚钱”的世界观，保留 12 波生存、自动攻击、虚拟摇杆、三个角色、武器/升级/商店/结算/存档等既有机制。

- 不修改角色属性、初始武器、移动动画和战斗数值。
- 不新增第四位可操作角色，不替换 `public/chars/*.png` 三张角色图。
- 不新增材料货币，不修改经济数值；只改题材包装和必要的展示。
- 不把游戏改成传统奇幻 RPG、清洁游戏或纯刷装备游戏。
- 本项目是非官方同人作品，文档和页面都不声称获得官方授权。

## 3. 世界观与页面文案

- 世界：小动物们住在有草原、坡道、集市和小铺的日常世界。怪物突然在镇外聚集，委托所发布讨伐工作；角色靠工作报酬购买食物、用品和强化。
- 首页：`哈奇猫` / `HACHICAT` / “接一份讨伐委托，赚取生活费与想要的东西” / “非官方同人作品”；标题下增加委托简报卡，显示委托方、地点、危险度与目标。
- 选角：`选择搭档`；“三个人，三种干活方式”；每张卡展示性格说明、擅长之处、起始装备与基础属性。
- 战斗：`第 n 波`、地点名、`讨伐目标`；不出现“清扫”“吸尘”“清洁度”。
- 成长：`又长大一点`；三选一保留。
- 补给点：`委托间隙`、`路边补给点`、`随身装备`、`装备整理`、`喝碗热汤`、`换一批`。
- 结算：`委托完成/中止`、基础报酬、沿途收入、完成奖金、评价、`击退`数、`再接一单`、`换个搭档`。
- 用品：九件用品各有独立图标（围巾、手套、发圈、布袋、糖果、饭盒、汤罐、铃铛、望远镜），不再共用属性圆点。

## 6. 装备、用品、成长

- 装备只改名称、说明、图标和弹道外观；`levels` 数值、冷却、范围、合成价格全部不动。
- 用品只改名称、说明与独立图标；`mods`、价格、叠加上限不动。
- 成长只改展示名和 flavor；`stat`、`amount`、`mode`、稀有度权重不动。
- 内部装备/用品 ID 为兼容保留，不作为玩家可见内容；敌人和角色精灵标识改为新语义。
