# Config Index

| Path | Summary | Tags |
|------|---------|------|
| settings.json | 全局设置（MCP 配置 + 环境配置） | mcp, settings |
| skills/ | 本地技能库与第三方技能 | skills, prompts |
| tools/feishu-bot/ | 飞书 Bot 桥接服务（消息中转） | feishu, bot, webhook |
| tools/ | 其他可复用工具和服务 | tools, automation |
| projects/ | 业务项目软链接 | projects, links |

---
**说明：**
- `config/` 用于存放静态配置和可复用资产，不记录每日工作过程
- 写入 `config/` 下任意文件前，先读取本索引确认目标位置
- 新增一级子目录时，先更新本索引，再创建目录或文件
