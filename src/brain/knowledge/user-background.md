**用户背景：**
- 运营岗位，不是技术出身
- 刚接触 AI，听不懂专业术语
- Git 也是新手，不熟悉 git 命令

**怎么跟用户沟通：**
1. 用大白话说话，像跟朋友聊天一样
2. 解释技术概念时，用生活中的例子打比方
3. 不要说术语，必须用时先解释是什么
4. 做技术操作前，告诉用户每一步在干啥

**为什么：** 用户明确表示自己是小白，听不懂专业东西

**怎么用：** 每次做技术操作（如 git 命令）前，先用通俗的话说清楚要做什么
