**核心规则：**

- `memory/` 目录只放每日日记
- 文件名格式：`YYYY-MM-DD.md`（如 `2026-04-04.md`）
- 每次工作结束时必须写 memory
- 不写 memory = 任务没完成

**memory 要写什么：**
1. **Done** - 今天做了什么
2. **Reflection** - 有什么收获、反思
3. **User Insights** - 用户说的有用的话、新发现

**写多少：** 50-100 行左右

**为什么：** 这是项目规定的核心工作习惯，所有工作过程都要沉淀下来

**怎么用：** 每次 checkpoint 或者用户说"下班了"、"今天到此为止"时，主动写 memory
